# AGENTS.md

## Agent skills

### Issue tracker

Issues live as GitHub issues on the `Eyhy/feishu-codex-bridge` fork (`origin`), driven with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the five canonical roles — `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix` — plus the `wayfinder:*` ticket-type labels. See `docs/agents/triage-labels.md`.

### Domain docs

single-context: one root `GLOSSARY.md` and one root `docs/adr/` shared by the whole repo. See `docs/agents/domain.md`.
